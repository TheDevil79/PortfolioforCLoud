# Vaibhav — Personal Developer Portfolio

A clean, static developer portfolio built for **Vaibhav** (Computer Science Student at VIT Chennai, 9.53 CGPA). Designed with an editorial, minimalist aesthetic suited for internships, hackathons, and technical networking.

Zero build step required. Simply open `index.html` in your web browser or deploy directly to GitHub Pages, Vercel, or Netlify.

---

## 📁 Project Structure

```text
├── index.html        # Main semantic HTML structure & portfolio content
├── style.css         # Clean, bespoke stylesheet & design system
├── script.js         # Lightweight vanilla JS for modal, copy email, and scroll
└── README.md         # Documentation & guide
```

---

## ⚡ Quick Start

### 1. View Locally
Double-click `index.html` to open it in any web browser (Chrome, Edge, Firefox, Safari).

### 2. Host on GitHub Pages
1. Push this repository to GitHub.
2. Go to **Repository Settings** &rarr; **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch** &rarr; `main` / `root`.
4. Your site will be live at `https://<username>.github.io/<repo-name>/`.

---

## ✏️ Customization Guide

All data, links, and text are stored directly in `index.html`:

1. **Social & Contact Links**: Search for `your-username` and `vaibhav.student@example.com` in `index.html` to update your GitHub, LinkedIn, and Email.
2. **Resume PDF**: Replace `#resume-file-link` in `index.html` and `script.js` with the path to your PDF resume (e.g. `assets/Vaibhav_Resume.pdf`).
3. **Projects & Skills**: Add or edit projects inside the `<section id="projects">` and `<section id="skills">` blocks.
